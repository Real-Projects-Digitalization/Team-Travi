## 📁 02_Ideation

This folder includes documents created during the brainstorming and conceptualization phase. The focus here was to refine ideas, define systems, and shape the foundation of the project vision.

### Files:

- **Storyboard.pdf**  
  A visual narrative outlining the user journey and interaction scenarios.

- **System Map.pdf**  
  Diagram representing the structure and key components of the solution.

- **The Test Card.pdf**  
  A hypothesis validation tool outlining what will be tested, how, and the expected outcomes.

- **Introducing_Team_Travi.pdf**  
  An introduction to the project team and the initial project idea.
