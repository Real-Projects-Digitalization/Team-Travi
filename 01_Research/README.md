## 📁 01_Research

This folder contains early-stage research and analysis files that help define the core problem, assumptions, and user needs. These documents were used to understand the problem space and ideate initial directions for the project.

### Files:

- **5-Why's.pdf**  
  Root cause analysis to identify the underlying issues.

- **Basic_assumptions.pdf**  
  A list of foundational assumptions to guide concept development.

- **HOW MIGHT WE.pdf**  
  Reformulated problem statements used to ideate possible solutions.

- **Problem.pdf**  
  Summary of the core problem, affected users, and context.

- **Crazy eight.pdf**  
  Rapid ideation technique used to generate multiple solution sketches.

- **SPIRIT_Toolbox_Now-How-Wow-Matrix.pdf**  
  Idea evaluation matrix to assess feasibility and innovativeness.

- **Target group and draft guidelines.pdf**  
  Definition of the target audience and initial design or development guidelines.

  - **Interview Results.xlsx**  
  Results from the interviews with Gen Zs.
